# بصيرة — مساعد إسلامي محلي بلا إنترنت

تطبيق أندرويد عربي صغير للمحادثة في **الأساسيات الإسلامية**. يعمل كاملًا داخل الهاتف ولا يتصل بأي نموذج لغوي أو خادم أو واجهة API.

## ما الذي يفعله؟

- يجيب عن مجموعة من الأسئلة الأساسية في أركان الإسلام والإيمان، الوضوء، الصلاة، الصيام، الزكاة، الحج، التوبة والآداب.
- يطبّع الكتابة العربية ويستخدم مطابقة كلمات وعبارات وثلاثيات حروف، مع ذاكرة موضوع قصيرة للأسئلة المتتابعة.
- يعرض مصدرًا مختصرًا مع الإجابة.
- يرفض مسائل الفتوى الشخصية أو المعقدة مثل الطلاق والميراث والتكفير والمعاملات الخاصة.

## الخصوصية

- لا يوجد إذن إنترنت في التطبيق.
- لا تسجيل دخول ولا تحليلات ولا إعلانات.
- لا تُرسل الأسئلة أو البيانات إلى أي جهة.

## تنبيه علمي

هذا **محرك استرجاع محلي محدود** وليس نموذجًا لغويًا عامًا، ولا يُعتمد عليه في الفتوى. المحتوى تعليمي مختصر، والمسائل الخاصة تُعرض على عالم مؤهل.

## البناء

يتولى GitHub Actions بناء APK تلقائيًا عند كل تحديث للفرع `main`.
